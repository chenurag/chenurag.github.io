# Chenura Gajanayake — GitHub Portfolio

Cybersecurity-focused personal portfolio built with **HTML, CSS and JavaScript**.

## Deploy on GitHub Pages

1. Create/open the repository `Chenura.github.io`.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
3. Commit the files.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Save.

Your portfolio will be available at:

`https://chenura.github.io/`

## Customize

Update the project cards, social links and learning timeline in `index.html`.

The GitHub contribution snake expects:

`https://raw.githubusercontent.com/Chenura/Chenura/output/github-contribution-grid-snake.svg`

If your snake workflow uses a different username/repository/output path, update the image URL in `index.html`.
